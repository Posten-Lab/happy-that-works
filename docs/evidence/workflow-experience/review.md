## Findings fixed during the review loop

- **Density and hierarchy:** repeated configuration buttons and long forms were replaced with a four-step flow, a team timeline, compact named agent rows, separate stage settings and collapsed advanced limits. Actual inner-scroll positions were asserted for lower-section screenshots; a full-page browser capture alone did not expose this React Native Web content.
- **Participant context:** headers and sidebar labels no longer expose a run UUID or internal phase identifier as the user-facing identity. Actual workflow and agent names are used when available. The participant footer has a 44px return action and does not offer a normal-session composer. [Planner session](25-planner-session.png), [executor session](29-executor-session.png).
- **Transcript clarity:** exact coordinator assignments are summarized as Assigned task, preserving the original in a disclosure. Strictly validated structured responses appear as neutral Agent response, with blocking findings visible and original JSON available. Interim model text does not synthesize the coordinator's task status. Ordinary session messages and ambiguous JSON retain their normal rendering. [Assignment](57-executor-assignment.png), [response](29-executor-session.png).
- **Approval context:** Read agreed plan appears before Approve and selects/scrolls to the plan. The real gate check observed the heading at y=175, then cancelled without execution approval. [Approval](54-plan-approval-final.png), [plan anchor](55-plan-anchor.png), [gate receipt](gate-validation.json).
- **Responsive actions:** the desktop Start action is capped at 240px. At 320px the workflow card's Run action wraps without overlapping its three agent avatars. Prompt height expands and shrinks with content. [Responsive measurements](supplement-validation.json).
- **Theme and flags:** enabled switches now use the intended white thumb/gold track on web. The Agent library link respects its own existing feature flag, independently of the workflow flag.
- **Failure accuracy:** latest execution is distinguished from earlier attempts. A malformed reviewer response remains an interruption until a valid result arrives; no parser or approval requirements were weakened to make the walkthrough pass.
- **Background Git polling:** workflow participant RPC connections close at the end of a turn. Viewing their retained transcript had registered a persistent project poll tied to that ended session, producing an RPC error after return to the workflow. Managed participants now cannot own that background poll; metadata is checked again before queued fetches and stale registrations are removed. Ordinary-session Git status behavior and shared-project cached status are covered by regression tests.
