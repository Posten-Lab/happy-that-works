# Talos Brand Bundle

Generated logo asset bundle for Talos.

## Contents
- `masters/` — high-resolution transparent color, black, white, and simplified marks plus common PNG sizes.
- `app-icons/` — dark and light app-icon treatments at 64–1024 px.
- `web/` — favicon PNGs, multi-size `favicon.ico`, Apple touch icon, PWA icons, and a sample `site.webmanifest`.
- `ios/AppIcon.appiconset/` — Xcode-ready icon set using the dark app-icon treatment.
- `android/` — legacy mipmap launcher sizes, Play Store 512, plus adaptive foreground/background PNGs.
- `macos/` — common icon sizes and `Talos.icns` where supported.

## Notes
The source artwork was AI-generated raster artwork, so this bundle contains PNG/ICO/ICNS assets rather than a true vector SVG. Resized assets are derived from the high-resolution masters using high-quality Lanczos resampling.
